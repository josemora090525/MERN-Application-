# Guia de Instalacion y Configuracion

Este documento proporciona instrucciones paso a paso para configurar y ejecutar el proyecto.

---

## 1. Requisitos Previos

Antes de comenzar, asegurate de tener instalado:

### Node.js

Node.js es el entorno de ejecucion de JavaScript para el backend.

- Descargar desde: https://nodejs.org
- Version recomendada: 18.x o superior
- Verificar instalacion: `node --version`

### npm (Node Package Manager)

npm viene incluido con Node.js. Es el gestor de paquetes para instalar dependencias.

- Verificar instalacion: `npm --version`

### Git

Git es el sistema de control de versiones.

- Descargar desde: https://git-scm.com
- Verificar instalacion: `git --version`

### Editor de Codigo

Se recomienda Visual Studio Code:
- Descargar desde: https://code.visualstudio.com

Extensiones recomendadas:
- ES7+ React/Redux/React-Native snippets
- Prettier - Code formatter
- ESLint
- Tailwind CSS IntelliSense
