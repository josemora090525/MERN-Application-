## Glosario de Terminos

| Termino | Definicion |
|---------|------------|
| API | Interfaz que permite la comunicacion entre aplicaciones |
| Backend | Parte del servidor que procesa datos y logica |
| Frontend | Parte visual con la que interactua el usuario |
| CRUD | Create, Read, Update, Delete - operaciones basicas |
| Endpoint | URL especifica de una API |
| Middleware | Funcion que se ejecuta entre peticion y respuesta |
| Token | Cadena de texto que representa autenticacion |
| Cache | Almacenamiento temporal para acceso rapido |
| CDN | Red de distribucion de contenido |
| ODM | Object Document Mapper (Mongoose) |
| Hook | Funcion especial de React |
| State | Estado o datos que maneja un componente |
| Props | Propiedades pasadas a un componente |
| Componente | Pieza reutilizable de interfaz |
